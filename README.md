# PraktikaTracker 📱💰

**PraktikaTracker** — це сучасний мобільний додаток для персонального фінансового обліку, розроблений на мові **Kotlin** у середовищі Android Studio. Проєкт створено в рамках навчальної практики з фокусом на архітектурну стабільність, асинхронність та якісний UX/UI.

## 🚀 Основні можливості
* **Повний облік транзакцій**: швидке додавання записів із зазначенням суми, категорії, дати та коментаря.
* **Розумна фільтрація**: можливість перегляду даних за двома критеріями одночасно — конкретною категорією та датою.
* **Динамічна статистика**: візуалізація розподілу витрат за категоріями у відсотках за допомогою ProgressBars.
* **Локальне сховище**: повна підтримка бази даних Room для надійного збереження даних без доступу до інтернету.
* **Адаптивний дизайн**: стабільна світла тема та коректна верстка для будь-яких діагоналей екранів.

## 🛠 Технологічний стек
* **Мова**: Kotlin.
* **База даних**: Room Persistence Library (Entity, DAO, Database).
* **Асинхронність**: Kotlin Coroutines (lifecycleScope).
* **Верстка**: XML (ConstraintLayout, RecyclerView, Material Design).
* **Середовище розробки**: Android Studio (macOS), Azul Zulu JDK 17.
